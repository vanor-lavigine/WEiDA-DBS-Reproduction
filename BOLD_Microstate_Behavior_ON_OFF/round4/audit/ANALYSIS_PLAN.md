# 临床评分与 BOLD 扫描访视审计方案

本轮以 `d96dc60cb7384fec576b321440160eb3ebfeebde` 的冻结队列为基线，核查 25 名 STN 患者的 50 次扫描和 15 次 HC 扫描。先按患者键、原始研究编号和 DBS 条件连接评分和扫描，再分别核查量表日期、扫描时间、药物状态、刺激状态和访视证据。原始记录中的冲突和时间精度逐项保留。

- 每个条件单独归类。`Confirmed same visit` 要求原始记录明确连接该次临床评估与该次扫描，例如共享明确访视标识或由原始访视记录直接关联。身份、DBS 条件和评分来源须经核实。`Confirmed same day` 只要求双方有可靠且相同的日历日期。`Near-time assessment` 只用于原始记录明确描述接近但无法确认同次访视的情形。`Different visit` 要求原始记录证实为不同访视，或来源独立且可核实的评分、采集日期不同。日期证据缺失或存在未解决冲突归为 `Date unavailable`。身份、条件连接或评分来源未核实归为 `Identity uncertain`，并记录具体原因。
- 计算评分时间减扫描时间。可比较的两端均具实际时刻时才计算小时差。仅有日期时保留日历日差。无可核验的时间基准时分别保留原值与来源。不同日历日期可判断跨日先后。同日评估在扫描前或后完成，需要可比较的时刻或直接顺序记录。近同期时间窗口留待原始差值分布核查后另行定义。
- 日期字段的原始批注优先解释单元格记录的事件。原件明确标注字段值是采集日期时，保留原值及批注，评估日期记缺失。日期冲突也须保留原始证据及裁定依据。
- 患者组 A 要求 ON 和 OFF 分别为 `Confirmed same visit`。组 B 的身份、两种刺激条件与评分来源均可信，但至少一端无法确认同次访视。任一端核心链接无法核实即为组 C。
- HC 审计按扫描键复核是否有运动评估原件、人工评分和正式零分，并独立核查与患者计分方案的可比性及同次访视证据。缺失保留为缺失。所有临床信息逐条留在本地私有目录。
- 分别核查扫描条件标签与刺激实际编程记录、评分时药物标签与扫描时药物证据。只有原始切换记录和兼容扫描时刻能支持稳定时长。记录扫描时间戳中的缺失、冲突和采集顺序。
- 同期关联分析预定义为复用第三轮主方案，在 A 组评估四态 Coverage 的 ON−OFF 变化与五种原人工重算评分的相对改善率。按同一双侧 Spearman 和 BH20 执行，每项至少需 3 个有效且非恒定的配对。若 A 组连最低可计算样本数也达不到，保留原 25 人分析为历史评分探索结果。组 B 单列，原三轮及冻结影像流程保持原样。
