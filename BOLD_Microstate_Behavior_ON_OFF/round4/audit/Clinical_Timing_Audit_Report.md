# STN-DBS 临床评分与 BOLD 扫描访视审计

覆盖冻结 A3 队列的 25 名 STN 患者、50 次 ON/OFF 扫描及 15 次 HC 扫描。原始来源中，A 组 **0 人**可确认两种条件的评分与扫描各自属于同一访视。B 组 **25 人**的身份、DBS 条件和评分来源可核实，至少一端缺少同次访视凭证。C 组 **0 人**的核心链接无法核实。

## 患者评分与扫描对应

| 原始记录支持的状态 | ON（次） | OFF（次） | 合计（次） |
|---|---:|---:|---:|
| Confirmed same visit | 0 | 0 | 0 |
| Confirmed same day | 22 | 21 | 43 |
| Near-time assessment | 0 | 0 | 0 |
| Different visit | 2 | 2 | 4 |
| Date unavailable | 1 | 2 | 3 |
| Identity uncertain | 0 | 0 | 0 |

两端均有同日证据而缺少明确访视连接的患者有 **21/25 人**。本轮要求原始访视标识或原始记录直接关联，才确认同一次访视。未设置近同期小时阈值。

47/50 次可比较日历日期。按评分日期减采集日期，2 次为较早日期，43 次同日，2 次为较晚日期，中位数 0 天，范围 -28 至 7 天。精确评分与采集小时差可计算 **0/50 次**。日期精度依据原单元格格式和值核查。跨日评估可从日期确定先后，同日评估的先后无法从日期确定。日差分布及扫描间隔见[时间差汇总](Timing_Difference_Summary.csv)。

两份评分工作簿中核对了 54 条原始 STN 评估记录，身份、记录日期、刺激和药物条件以及全部 33 项人工评分逐项相符。冻结分析的 50 次评估与归档重算数值核对一致。辅助人口学表有 1 人姓名写法与主来源有差异，原始采集名册与两份评分原件的身份信息吻合。当前比较工作簿的字节哈希与历史 V8 收据不一致。逐项核对结果针对本轮可访问的版本。原表运动检查总分为 33 项重算，正式量表版本待核实。

原 V8 的日期匹配按日历日期核对。本轮检查了原始单元格批注，发现 1 条历史匹配记录的日期值明确指扫描日期。这条记录没有独立评估日期，归为日期不可用。评分来源和身份仍经核实。其他记录采用已匹配的 DICOM 采集日期对照评估日期。旧标签按评估次数列在[运行清单](Clinical_Timing_Audit_Manifest.json)。

## HC 临床评分

15/15 个冻结 HC 扫描键与原始采集名册、健康组登记匹配。健康组登记没有运动评分字段。查阅 6 份工作簿的 27 个工作表，包括原始条目、比较工作簿附表和既往归档，并核查归档临床导出。找到 0/15 份可核验的 HC 运动评估及 0/15 个实测零分。与患者相同计分规则的可核实记录为 0，评分与扫描同次访视的可核实记录为 0。缺失的 HC 临床分数以 NA 保存。此前所述的 15 个零分无可追溯的评估原件或赋值记录，HC 暂只作影像参照。

## 扫描顺序、刺激和药物

原始 DICOM 头字段归档支持 48/50 次患者扫描的采集日期与时刻，其中 4 次与名册候选日期有差异。48 次 DICOM 时刻与归档原始 BIDS sidecar 时刻一致。BIDS 时刻中的单数字秒按原数值解析。采用经过序列信息确认的 DICOM 日期，并在本地保存两者及其来源。HC 的 BIDS 时刻有 15 份可查，HC 名册候选日期尚无独立 DICOM 证据。

**24/25 对先 ON 后 OFF**，0 对先 OFF 后 ON，1 对顺序未核实。24 对可计算 OFF 减 ON 的采集时间间隔，中位数 1.833 小时（109.98 分钟），范围 0.698–2.865 小时（41.86–171.90 分钟）。

原始评分记录显示 medication OFF 的评估为 ON 条件 25 次、OFF 条件 25 次。两次扫描的药物状态均有记录、因而可比较的人数为 0/25。原始采集与配对证据支持 DBS 条件标签。可核验的实际切换时刻、刺激状态稳定时长和扫描期间刺激状态记录分别为 0、0、0 次。扫描间隔只表示两次采集的时间差。固定扫描顺序限制 ON/OFF 差异的解释。分条件证据见[药物与刺激审计](Medication_Stimulation_Audit.csv)。

## 分析决定

A 组 0 人，未达到预定义关联所需的最低 3 对。本轮未计算同期关联，也没有扩大样本或对 B 组另行检验。前三轮 25 人结果保留为历史评分的探索性分析。临床变化或微状态变化本身无法建立两者的同期关联。

基线完整性核验覆盖原始评分接收件、冻结 A3 影像特征及前三轮分析。扫描核验使用本地归档的原始采集与头字段。原采集服务器的无交互认证未通过，远端 DICOM 文件本轮未复读。既往采集档案核查中有 11 个目录不可读。同期临床评估无法从可核查档案恢复，是本队列的设计限制。
