# 第三轮 Coverage 与运动改善率分析方案

2026-11-27 在计算第三轮关联之前保存。远端基线为 `eb4a9ab9222ce883787a9183c925ec4e0fe00682`，文件树为 `eb926317e1589e80ff1e83a80ab370ac1ba5b7ef`。使用同一已分析队列，属于探索性延伸。前两轮协议、报告、统计结果保持冻结。

- 使用原 A3 的 25 对 STN 患者，按患者键、冻结 ON 扫描键、OFF 扫描键核对一对一关系。AAL78、K=4、TR=2.1 秒、0.01–0.08 Hz、N0/G1/S1、λ=0.04、五折与原共用有效窗固定。读 V6 原窗 Coverage 及扫描和配对清单，原有对齐状态号直接使用。核对每个扫描四态比例和及每名患者差值和，容差 1e−12。HC 不进入相关分析。
- Coverage 是有效扫描时间占比，以 0 至 1 计算，变化定义为 ON−OFF。四态变化方向人数以 1e−12 作浮点零差判定，仅用于描述。相关使用原始数值和标准并列秩。
- 复用原 33 项人工条目重算的总分，以及强直、运动徐缓、震颤和三项步态与平衡探索性合计。绝对改善量为 OFF−ON，逐人改善率为 (OFF−ON)/OFF。OFF=0 只使该项改善率不可用。无改善和恶化值原样保留。
- 主分析对四态 Coverage 变化与五项改善率作 20 次双侧 Spearman，最低 3 个有效配对，任一变量恒定时保留 NA。统一 BH20，q<.05。不可计算时在校正中占 P=1 槽位，输出保留 NA。名义结果为原始 P<.05 且未通过本轮校正。
- 同一状态和症状的次要对照复用主分析实际患者集合，将改善率换为绝对量，完整 20 项单独 BH20。两个家族固定，既有临床比较、持续时间关联及其他结果沿用原校正范围。没有重抽、置换、协变量拟合或其他终点。
- 公开结果为汇总数值、中文报告及相关热图。逐人临床影像配对、逐格样本及精确散点保存在原被 Git 忽略的私有目录。新入口只读复用已有私有输入，并记录输入版本及哈希。
