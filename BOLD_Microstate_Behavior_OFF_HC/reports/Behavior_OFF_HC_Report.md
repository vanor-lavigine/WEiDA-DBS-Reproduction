# DBS OFF–HC 组间报告 · BOLD 微状态持续时间

**组间比较为 DBS 关闭（OFF）的 25 名 STN 患者与 15 名健康对照（HC）。** 运动症状关联在同一批 25 名 OFF 患者内部进行，HC 提供影像参照。

**四个状态中，只有 M4 平均持续时间的 OFF–HC 差异通过 BH-FDR。** 原窗中 OFF 比 HC 平均长 4.31 秒（q = 0.000119），固定 FD 删帧后仍长 3.62 秒（q = 0.00175）。在 25 名 OFF 患者中，四态持续时间与运动总分、强直、运动徐缓、震颤、步态平衡的 20 项关联均未通过校正。22 人日期核实子集及固定删帧窗各为 0/20。**本轮观察到 M4 的组间影像差异，患者内症状关联尚缺足够证据。**

## 评分与样本核查

在原工作表核对实际列名后，按 H:P、S:Z、AC:AD、AF:AS 的 33 个真实评分重算运动总分。强直取 J:N，运动徐缓取 O:P、S:Z、AI，震颤取 AJ:AS。步态与平衡取 AD、AF、AG 三项，是预定义探索性合计。Excel 的 AI 列为真实的全身自发动作评分。预测列 Q:R、AA:AB、AE 和 AT 缓存总分均从计分排除。工作簿写作 UPDRS-III，正式量表版本未确认。另一工作簿按已核对的访视键逐项对照，27 条 STN OFF 记录的 891 个真实条目全部一致。

27 名有 OFF 评分的 STN 患者中，25 名与冻结影像成功连接，另外 2 名在冻结影像名单之外。纳入 25 人均为 **DBS OFF**，用药字段另行记录为 **med_off**。身份连接保留了一条先前已裁定的姓名异写。日期不限主分析包括 22 名日期核实、2 名日期冲突和 1 名证据不足；22 名核实者单独复核。健康参照名单的 16 条人口学记录中，15 条与冻结 HC 扫描对应，评分表没有相应 HC 评分。HC 只提供影像参照。 [既有评分核查](../../BOLD_Microstate_STN_Original_Scores/reports/STN_Original_Score_Audit.md)

M2 与震颤的原始 P 为 0.0443，BH20 q 为 0.748。固定删帧后，M3 与强直的 ρ 为 +0.480，原始 P 为 0.0152，BH20 q 为 0.305。两个敏感性家族仍没有通过项。点估计可供描述，现有结果没有给出涉及强直、迟缓、震颤或步态平衡的一致校正后证据。M4 与总分的 ρ 在原窗、日期核实、删帧分析中分别为 +0.091、−0.009、−0.080。分析未作年龄、病程或平均 FD 协变量调整。

既往同条件严重度分析已经以相同 25 人检验 M4 与 OFF 总分，旧 Spearman ρ = +0.0908、置换 P = 0.6710、阶段 BH11 q = 0.7381，后续累计 BH20 q = 0.7895。本轮以重算总分和预设简单 Spearman 复核得到相同点估计与名义 P（0.6660），BH20 q = 0.9514。旧版本保留其原置换、来源资格及现有历史校正。本轮校正只覆盖当前家族。
