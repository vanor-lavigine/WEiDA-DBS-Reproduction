# WEiDA 与 BOLD 微状态同扫描对照

## 队列与可比性

从本地作者代码 R2025b、K=4、种子 0 档案读取 65 次逐扫描标签及特征。核对扫描编号、条件、配对键、ROI SHA、有效帧和 MAT 阵列。两种方法读取的 ROI 阵列逐元素相同。WEiDA 时钟覆盖 13,647 个有效帧。三次扫描各缺一帧。
逐扫描重新计算占用率、作者边界删失段长及 4×4 下一 TR 转换，并与归档逐项核对。原特征与原质心复核通过后，按原 VAR 公式重算局部 metastability。参见 [原 WEiDA 方法](WEIDA_STATISTICAL_PROTOCOL.md) 和 [输入校验](../results/Input_Verification.json)。

原论文使用 16 名 HC 与 25 对患者。本地比较严格使用 V3 的 15 名 HC 与 25 对患者，论文的逐人身份映射未得到核验。WEiDA 原复跑使用 0.04–0.07 Hz 的相位特征和全队列模板，V3 E04 使用已有 0.01–0.08 Hz 缓存幅值和五折模板。同扫描控制了输入队列和 ROI 顺序，分析带宽和模板训练设计仍有区别。跨方法差异不能单独归因于状态表征。

五个留出折各有四个 Hungarian 候选。3/20 同时达到 |r|≥0.60 和双向余量≥0.05，候选 |r| 范围 0.3824–0.9456。跨折排列一致性未通过。完整四态对应未建立，跨方法同类比较限定在无状态编号的整体指标。

本地 WEiDA 编号 W1–W4 和 V3 微状态 M1–M4 各自保留。局部 VAR 使用 WEiDA 特征图及原始方差尺度。微状态适配离散度使用中心化单位幅值图及极性不敏感的平均距离。二者作为各方法内部的局部离散证据阅读。原 WEiDA 段长删去边界段，原转换分母包含自循环。用于同定义对照的 WEiDA 段长和转换从归档标签重新计算，原口径另有完整结果。

## 研究结论

| 原论文发现 | V4 在冻结队列中得到的证据 |
| --- | --- |
| V-VA/SM 的占用率 OFF 低于 HC，ON 相对 OFF 增加。LMB-SM 在 OFF 的占用率更高。 | 微状态检测到占用率变化。M3 Coverage（OFF-HC，均值差 -0.08245）、M3 Coverage（ON-OFF，均值差 +0.05511）。论文状态身份在微状态中无法验证。 |
| V-VA/SM 的局部 VAR 在 OFF 较高，ON 相对 OFF 降低。 | 局部离散程度的疾病差异在两种表征中都有体现。本地 WEiDA 有 0 个 ON−OFF 主指标同时通过两种 Holm。 |
| 论文报告通往 V-VA/SM 的若干转换变化，组比较使用未经校正的 P。 | 本地将 12 条转换和三个对比全部纳入校正。微状态和 WEiDA 的双 Holm 转换结果分别为 0 项和 0 项。 |

占用率及局部离散的结果与原论文部分现象方向相近。四态对应未达到预设标准，无法确认微状态复现了论文所指的具体 PMS 中的疾病异常与刺激变化。同扫描 WEiDA 与微状态在整体指标的直接比较见下表。论文的疾病、刺激和转换结果来自 Fig. 3–4。[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13280393/)

微状态特有的已检出读出为 M3 GEV（OFF-HC，均值差 -0.03609）、M3 GEV（ON-OFF，均值差 +0.01361）。GEV 反映幅值图对模板的拟合和占用，结果与同状态的 Coverage 及离散度存在定义关联。

微状态段长通过双 Holm 的对比为 M1 Duration（OFF-HC，均值差 +0.6543 s）。本地 WEiDA 的同定义状态段长与边界删失段长合计 0 项通过双 Holm。

对照表的方向一致指两种方法的均值差同号。方向不一致或仅一侧检出属于描述性对照。两种方法差异大小的显著性未另作交互检验。
