# V6 最终科学解释

**在这批 25 名 PD 患者中，DBS 条件与 BOLD 微状态动力学变化相关。** 两个预定主要终点显示，ON 扫描的 M1 对全局方差的解释贡献增加，M4 每次停留平均时间缩短。两项在 FD、DVARS 和可核实扫描顺序的子集分析中均有支持。这一队列的 24 个已核验配对均先 ON 后 OFF，刺激条件与扫描先后重合。结果描述本队列的条件差异。[主统计](V6_ON_OFF_Microstate_Results.md) · [质量审计](ON_OFF_Data_Quality_Report.md)

| 问题 | 结果 |
|---|---|
| 1. M1 GEV 是否变化？ | ON−OFF 为 +1.17 个百分点（95% CI +0.69 至 +1.66），21/25 上升。两项家族置换 Holm P=0.00060，FD P=0.00080。 |
| 2. M4 停留是否缩短？ | 平均停留 −3.07 秒（95% CI −4.75 至 −1.43），19/25 缩短。两项家族置换 Holm P=0.00190，FD P=0.00170。删去边界段后，均值缩短 3.28 秒。中位数和 P75 单独报告。 |
| 3. M1 出现率增加？ | +0.40 次/分钟，次要家族置换 Holm P=0.02500，FD P=0.01800，DVARS P=0.05749。 |
| 4. 全局切换率改变？ | +0.84 次/分钟，次要家族置换 Holm P=0.03040，FD P=0.00660，DVARS P=0.05749。 |
| 5. 整体转换矩阵改变？ | V6 非对角概率整体变化通过探索性 Holm（置换 0.00180、FD 0.00680）。M4→M1 路径仅在未调整置换通过路径 Holm，FD 与 DVARS 调整后未通过。 |
| 6. 个体模式是否不同？ | 四项方向向量与其余组均值同半空间的有 21/25。探索分群为 9 和 16 人，描述内部聚集，临床分型未验证。 |
| 7. 是否与 UPDRS 改善相关？ | BLOCKED。历史导出可对应患者与开关，原始评分访视与扫描未能核实。 |
| 8. ON 是否更接近 HC？ | 平均距离缩短 0.124，区间含零，配对置换 Holm P=0.21938。健康趋近和 ON–HC 等效性均未建立。 |
| 9. 哪些通过多重比较？ | 两项主终点是 A。次要家族中 M1 出现率、全局切换率、M1 占用通过未调整置换 Holm，前两项在 FD 后仍通过。探索性两项整体、去边界后的 M4 平均停留也通过 FD 家族 Holm。M3 空间离散只在 FD 设定达到 Holm。效应与全部未过阈值项目见总表。 |
| 10. 对 FD 或时序有何限制？ | M1 占用和 M4→M1 对头动模型敏感。M1 出现率和切换率在 DVARS 层面未过 Holm。用药时间未核实。固定扫描顺序与 DBS 条件的独立影响无法由这些资料估计。 |

V6 新的整体转换和配对占用组成结果是同队列的探索性证据。主要两项沿用 V4 已经观察到的结果，当前的方向、留一和质量敏感性增加了对这批配对数据的描述。独立验证可使用随机平衡顺序、同样的扫描窗口和记录完整的同期 UPDRS。以两项主终点校正的双侧 α=0.025、15% 完整配对损耗估算，dz=0.35 时 80% 功效需招募 96 名患者（192 次扫描），dz=0.40 时需 73 名（146 次）。90% 功效分别需 123 和 96 名。[样本量表](../results/Paired_Sample_Size_Planning.csv) · [完整标量](../results/ON_OFF_Feature_Summary.csv) · [转移报告](V6_Transition_Dynamics.md)
