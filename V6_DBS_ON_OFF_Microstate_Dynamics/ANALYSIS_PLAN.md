# V6 配对微状态分析方案

本方案在读取 V6 条件差异前锁定。V4 五折 A3 模板、状态编号、原有标签与有效窗口固定。直接从 V4 冻结逐扫描特征读取各项指标。用原编号映射核对标签和派生数量。新增的停留分位数及边界敏感性按同一标签和 TR 定义计算。所有配对差异定义为 ON−OFF，健康参考距离缩短例外，定义为 OFF 距离减 ON 距离。推断单位为患者配对。

| 家族 | 检验范围 |
|---|---|
| 主要 | M1 GEV、M4 平均停留时间两项 |
| 次要 | M1 出现率、全局切换率及四态占用率六项 |
| 探索性停留 | 各态窗口中位数和 P75，排除各有效块首末段后的各态中位数和 P75，另加 M4 排除边界后的均值，共 17 项 |
| 探索性空间离散 | 四态的平均模板空间离散。M3、M4 是重点解读项 |
| 探索性整体 | ON−OFF 的 12 条非对角转移概率及三维 Coverage ILR，两项 |
| 探索性路径 | 全部 12 条相邻转换路径，对应模型的整体置换 Holm 通过才作定位推断 |
| 模板拟合相关 | M1 GEV 改变量与 M1 Spatial Dispersion 改变量，单项探索性 Spearman |
| 健康参考 | V5 定义的距离缩短与沿用 V5 的 ON–HC Coverage Energy，共两项 |
| 探索性临床 | 仅在能核验原始评分与扫描访视配对时进行四项 Spearman，报告 BH 和 Holm |

连续量先对配对差用 Shapiro–Wilk，P≥0.05 时原始 P 使用双侧配对 t，否则用双侧 Wilcoxon signed-rank。两项原始 P 都保留，Wilcoxon 对 12 位小数舍入后的差使用正态近似与零差剔除。置换主推断用 10,000 个不同符号向量翻转患者差值，检验双侧均值。仅在有效配对数不足以生成 10,000 个不同向量时穷举所有可用向量。常数差可用符号翻转，标准化效应在方差为零时留空。点估计是均值差、中位数差和 Cohen dz。95% 区间基于固定模板的 2,000 次患者配对百分位重抽，另报告普通 t 区间作为诊断。记录缺失、失败次数、均值方向保留率。只要是向量，就保留各坐标估计与区间。整体向量效应为配对均值向量的欧氏长度，其区间是幅度描述。向量方向保留率为重抽向量与观测均值向量同向内积的比例。[配对效应量](https://doi.org/10.3389/fpsyg.2013.00863)

患者内模型为 `ΔY = β0 + β1 ΔFD + ε`，检验 ΔFD=0 时的截距。FD 从 210 帧原始时钟的冻结扫描平均值计算，每个患者贡献一条差值。采用缩减模型残差的 Freedman–Lane 符号翻转，标量用 HC3 t，向量用 HC3 协方差及固定 0.10 的各向同性迹收缩 Wald。另逐项对 Δ标准化 DVARS 做同样的敏感性分析，并在有可核实扫描顺序的完整配对上重算未调整结果。扫描间隔的 Spearman 仅作为时序诊断。原始检验、置换、FD、DVARS 和有记录扫描子集各自按预定家族校正。先后顺序与条件重合时，数据不能估计两者的独立效应。后续同日交叉研究可按 ON→OFF 与 OFF→ON 随机平衡，固定切换等待时长与用药标准并记录实际时间。[Freedman–Lane](https://pmc.ncbi.nlm.nih.gov/articles/PMC4010955/)

整体转移以 12 条非对角概率的配对差为向量，分母保留该源状态的全部有效转换（含自循环）。四条对角线、原始次数和分母全部保留。相邻性沿冻结时钟确定，不跨无效帧。用预先固定的配对收缩 Wald 和 10,000 次符号翻转。对面向同一个整体检验的 12 条路径同时做 Holm 和 BH，门槛按每类模型独立判断。未开启时，逐项数值及区间用于描述。

健康参考沿用 V5 的 0.5 帧伪计数及三维 Helmert ILR，以 15 名 HC 的 ILR 均值作参考中心。单侧检验正的距离缩短，与 V5 沿用同一重抽种子。2,000 轮嵌套 Bootstrap 独立重抽 HC 和完整 PD 配对并重估 HC 参考中心。距 HC 的配对均值和中位数、dz 和区间均保留。ON–HC 独立组 Coverage Energy 读取已冻结 V5 模型原始结果，提供 V5 原家族与 V6 两项健康参考的校正。未设有可外部支持的等效界值，TOST 未定义。[等效界值方法](https://doi.org/10.1177/1948550617697177)

变化方向按 ±1e−12 的数值容差统计，报告均值、中位数、自助区间和 Wilson 比例区间。未设临床响应阈值。对配对变化作 20% 修剪均值、精确符号检验和每次留一对敏感性分析。M1 GEV 与 M1 离散关联对同一患者两个差值作 Spearman，另做带 FD 的秩回归敏感性。用 M1 GEV、M4 平均停留、M1 出现率和全局切换率四个标准化差值描述变化模式，计算每名患者与其余患者平均差向量的夹角余弦。固定两类 Ward 作探索性图示，报告 silhouette 和固定 500 次 80% 患者不放回子样本的分组重复度。四态覆盖率另按逐态方向报告，其总和依旧固定。聚类结果无临床分型阈值。

临床关联只采用可追溯的逐人临床原始记录或审定逐访视表，同时验证参与者、条件及访视连接键或确切评估日期。历史研究导出仅按患者和开关分配的分数用于证据审计。评分与扫描访视匹配且相关系数可估计时，计算四个预定 Δ 特征与 OFF−ON 评分改善的 Spearman 相关、成对自助区间及逐对留一，报告 FD 敏感性。资料不足时登记 BLOCKED。药物时间只据可核实来源登记，不填补缺失。

Holm 与 BH 按上述家族及模型分别计算。A 为置换 Holm 通过的两项主检验，B 为通过预定非主要家族置换 Holm 的终点，C 为仅名义 P 或 BH 支持的终点，D 为余项。各 model 另保留原始方法 Holm 用作对照，转换路径的门槛覆盖分类。非置换的 Spearman 结果保留原始、置换及各自校正。所有数值均来自本队列补充分析。功效按双侧 α=0.05/2、dz=0.35/0.40、80% 或 90% 功效及 15% 配对损耗规划，观察到的效应量只作独立的规划敏感性。
