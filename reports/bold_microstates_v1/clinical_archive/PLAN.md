# 归档运动评分补充分析的计算约定

2026-11-23。在读取本轮临床关联数值前固定以下做法。本次沿用 v1 的问题、四状态模板和统计函数。历史 WEiDA 评分表已经按患者和 DBS 开关条件对上。评分日期、评分时用药情况及量表是否为 MDS 修订版缺少逐访视凭证。家族 B、C 的本次运算属于归档评分的探索性分析。原协议所要求的完整访视核验仍待补充。

| 项目 | 固定做法 |
|---|---|
| 成像 | V100 真实队列，67 次扫描的有符号四状态模型。读取冻结的逐扫描指标。26 对 STN 纳入家族 A，15 名 HC 参与原模板训练。 |
| 家族 A | 对 4 个状态的覆盖率、出现率、持续时间分别检验 ON−OFF，12 项内 Holm 校正。重算结果与已归档的组层输出核对。 |
| 家族 B | 24 名有评分的共有患者。以同一人的影像 ON−OFF 与运动总分改善 OFF−ON 的绝对分差作 Spearman 相关，12 项内 Holm 校正。 |
| 家族 C | 同上。将 OFF 期间四个状态各自的持续时间与同条件归档总分作 Spearman 相关，4 项内 Holm 校正。 |
| 评分版本 | 主读四状态 66 次扫描存档的 `UPDRS3`。先确认其与另一份三状态存档的 50 条总分相等、可由 12 个共同分项逐行重算。用另一份四状态存档在相同 24 人中重复 B、C，再单列三份存档 OFF、ON 总分均一致的 17 人。三种方案在计算前确定。 |
| 数值 | 使用原统计函数，双侧、患者为单位、10,000 次置换、2,000 次患者 bootstrap、种子 20261121。每个版本保留全部检验位置。以家族内 Holm 校正 p < 0.05 判定，区间为各指标边际 95% 区间。 |
| 头动 | 描述两种条件的平均 FD，并查看 OFF 评分与 OFF 头动、评分改善与头动变化的秩相关，作为混杂线索。 |
| 微状态与亚稳态 | 按已经提交的脚本独立复算切换率与 WEiDA S2 局部亚稳态的影像关联，对照前次两套处理的结果。该指标不使用临床评分。 |

不按临床结果选择状态、评分版本、患者或频带。临床分值及逐人关联仅在评分所在服务器私有环境中处理，对外输出汇总表和组层图。
