# M4 退出动力学

OFF 和 ON 各有 310 次实际退出，25 人两侧均有出口。按每名患者的有效扫描时间计算，退出频率从 1.825 变为 1.833 次/分钟，差值为 **+0.008 次/分钟**［95% CI −0.297，0.286］，置换 P=0.9608，Holm6 P=1.0000。调整 FD 与 DVARS 后均未通过各自的 Holm6。

| M4 退出后进入 | OFF | ON | ON−OFF 百分点［95% CI］ |
|---|---:|---:|---|
| M1 | 27.57% | 42.50% | +14.93［3.84，26.90］ |
| M2 | 44.13% | 31.98% | −12.14［−22.06，−4.20］ |
| M3 | 28.30% | 25.52% | −2.78［−12.04，5.87］ |

三者的条件均值对患者等权。M1 和 M2 各自的区间用于展示组成的估计方向。本轮采用预定三部分 Helmert ILR 整体检验，原始 P=0.0433，Holm6 P=0.1732。FD 调整原始 P=0.0733，Holm6 P=0.2932。DVARS 调整原始 P=0.0818，Holm6 P=0.3272。三个原始置换 P 与上一轮 H6 完全一致。此前 FD 模型的 Holm6 P=0.4398 对应上一轮不同的六项家族。

退出数等于 M4 段数减去右截断段数，50 次患者扫描均满足。右截断段在 OFF 有 4 个，在 ON 有 9 个。`Duration × Occurrence = Coverage` 也是逐扫描恒等式。`1 / Occurrence` 是每次出现分摊的整窗时间，在 50 次扫描中均不等于 M4 平均持续时间。平均持续时间除以这个倒数恰好得到 M4 占用率。

以 M4 占用时间作分母的退出强度描述性增加 1.45 次/分钟［0.47，2.50］。它与整窗退出率共用退出次数，且分母随 M4 占用而改变。现有估计显示去向有重分配趋势。持续时间缩短的主要数学来源仍是较低占用率。
