# V7 冻结微状态分解分析方案

本轮复用 V4 的 40 名参与者、65 次扫描和 V6 的 25 个患者配对。A3 的标签、有效窗口、原编号和五折模板保持冻结。读取已有的逐帧 GFP、拟合值和标签。ROI 自相关仅在已有 F1 时序上做诊断计算。所有差值的方向为 ON−OFF。

## 两项已支持的影像变化

- M1 GEV 按 `GEV₁ = W₁ × F₁` 分解。`W₁` 是全窗 GFP² 中落在 M1 的比例，`F₁` 是 M1 内以 GFP² 加权的拟合相关平方。复用 V6 对匹配状态相关值的裁剪规则。配对差采用对称 Shapley 平均，贡献以 GEV 百分点报告。
- M4 平均持续时间以同一窗内的 `Coverage₄ / Occurrence₄` 复算。`Δlog(Duration₄) = Δlog(Coverage₄) − Δlog(Occurrence₄)`。原秒数和分量的对数单位均保留。两侧都具有状态和非零出现率才可取对数。另用两端均有有效邻帧的完整片段复核，再以原窗有效时间作两项率的分母。
- 总变化过小或组均值的患者 Bootstrap 区间跨零时，贡献份额容易失稳。比例由贡献均值除总差均值得到，组级还需超过预先设定的绝对阈值。逐人比例只在个体阈值通过后计算。

## M4 退出的频率与去向

退出事件是紧邻的有效 M4 帧转入任一非 M4 状态。用原窗有效时间归一化，右端无有效邻帧的状态段未产生可观测退出。用每位患者各条件的实际退出数计算三个原始去向概率。零退出的记录保留并标为组成不可估计。有实际退出的记录每格加 0.5 后作三部分 Helmert ILR。整体检验沿用 V6 收缩 0.10 的 Wald；同一预先指定的比较已有 H6 结果，本轮作重复核验。分别核对 `退出数 = 段数 − 右截断段数` 与 `Duration = Coverage / Occurrence`。另计算 `1 / Occurrence` 和单位 M4 占用时间退出强度，明确各量的分母。

## 六项推断

六项主检验按固定清单以患者级未调整配对符号翻转推断。标量采用配对差均值，组成为两维 ILR 联合 Wald。使用冻结的 V6 种子与 10,000 个不同的非原始符号组合。小样本时穷举全部非原始组合并保留原观察的加一项。联合患者 Bootstrap 2,000 次提供 95% 百分位区间，标量同时给出配对 `d_z`。FD 和标准化 DVARS 分别用 V6 的协变量调整模型，估计零头动变化时的截距或 ILR 截距范数。整体检验各在主模型及两个敏感性模型内用 Holm6 校正。不可估计的项保留行，校正中用 1 占位。边界、每条退出去向和取样分析提供描述性估计与区间。

## 网络与取样

使用公开的 MNI 空间 Yeo-7 紧掩模与本项目 AAL78 的实际体素重叠作描述性注释。报告覆盖程度、未分配量以及五折所有状态与冻结参考的相似度。皮层下区域在存在时应独立登记。

在原 210 帧时钟上取全窗、前 105 帧、后 105 帧和固定的中间 105 帧。每一窗沿用同一标签，不跨越无效帧。有效观察至少 200 秒且 M1 至少 10 帧的扫描进入该窗 GEV 的稳定性比较。M4 至少需 3 个两端完整的状态段。依照相同口径报告各窗可估计性、边界数、达标患者对和所有窗口共同达标患者对。少于 3 对时保留诊断并标为缺乏稳定估计。此分析评估扫描内取样敏感性。基于有效连续块核查各 ROI 在 48 帧内的自相关，报告 lag-1 和首个低于 `exp(−1)` 的时滞。
