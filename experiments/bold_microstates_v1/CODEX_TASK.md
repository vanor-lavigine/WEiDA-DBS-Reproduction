# 服务器 Codex 执行任务：微状态方法迁移实验 v1

## 目标

在现有 STN-DBS BOLD 数据上复现微状态的空间状态识别与时间指标框架，探索 EEG 中的状态持续时间—严重度关系是否出现于此数据，并考察 ON/OFF 与临床改善。读取同目录 `PROTOCOL.md` 后执行。

## 工作位置

- 仓库：`vanor-lavigine/WEiDA-DBS-Reproduction`。
- 分支：`experiment/bold-microstates-v1`。
- 保留现有工作区未提交修改；必要时用独立 worktree/checkout，不执行 reset/clean，不覆盖 main。
- 使用已有服务器连接与凭证，不猜 SSH 用户名、不新增凭证配置、不输出密钥。

## 立即执行的顺序

1. 优先读取 `reports/2026-11-21-v100-syn9-stn-hc.md`、此任务与 PROTOCOL。当前主输入是 **26 对 STN OFF/ON + 15 HC = 67 次扫描，每次 210×78 AAL78、TR 2.1 秒**。README 的 126-run/4S 是旧批次，不应取代今日专项报告。
2. 从现有 SyN9/WEiDA 任务日志、配置及 MAT 打包清单定位这 67 份 AAL78 TSV，以及已经确认的患者/条件映射。直接复用既有配对和统一 ROI 顺序。使用进入 WEiDA 窄带/Hilbert 之前的 XCP-D 0.01–0.08 Hz ROI 时序，不使用相位向量或静态 FC 充当 BOLD。
3. 建立独立输出目录和软件环境，记录版本，运行 `tests/`。将既有清单适配成 `runs.tsv`（run_id, roi_time_series, tr_sec, atlas=AAL78, format=nifti），并关联已有身份元数据。索引已符合 schema 时可用 `run.py index`，否则写只读字段适配器；不要求用户重填已有配对。
4. 执行真实数据 `fit --mode pilot --k 4`；可先用 `--limit 4` 做接口检查到另一个输出目录，然后完整运行。保持 K=4、100 初始化、seed=20261121；不依据显著性选参数。
5. 并行只读查找对应访视的临床量表和原来源证据。既有原数据位置：
   - `10.249.25.105:/media/hit/bfbee57b-6241-4ccb-9890-f9eb0e1e8ca7/PD_DBS_zcc/`
   - `10.249.25.105:/media/hit/bfbee57b-6241-4ccb-9890-f9eb0e1e8ca7/PD_TI_zcc/`
   主队列只用已确认 SyN9 STN/HC，不纳入 PD_TI_zcc 的 tTIS。核实评分与扫描/访视/用药对应；不要按文件顺序猜配对，不混入 TCP。
6. 核对全部 67 份时序为同一 78 区名称/顺序、210 帧，数值有限且非恒定；复用报告已有的技术/覆盖率证据，只对接口与文件完整性做必要核验。不要新增皮层筛选或重跑影像预处理。
7. 使用已有配对运行 `fit --mode analysis`，按患者等权建立共同模板，再执行 `stats`。临床分数缺失不阻断 ON/OFF 统计；缺失的临床项目写明原因。若清单与报告的 26 对/15 HC 不符，查具体记录，不自动改用旧的126-run批次。
8. 模板/指标合理后运行 K=5/6/7 的描述性敏感性分支；如时间足够，可运行 unsigned 极性对照。两者不追加显著性筛选，不取最小 p 作为主结果。
9. 生成 `reports/bold_microstates_v1/` 下的去标识汇总、真实命令/环境/数据范围、模板图、时间线、完整统计表与实际限制；原始时序和个体临床映射留服务器。将代码修复和汇总报告提交回同一实验分支。

## 验收重点

- 真实数据是否完成状态提取，而不只是测试通过。
- 状态是否由空间模式定义；临床数据没有参与选 K、选模板和挑种子。
- duration 使用秒，occurrence 使用次/分钟，coverage 为比例；恒等式和缺失边界符合定义。
- 所有拟合共用 ROI 标签和模板；同一人不因多个 run 被当成多个独立样本。
- 输出主 K=4 全部检验家族，不只呈现显著结果。M1–M4 不命名为 EEG A–D。
- 原文 EEG 基线关联与本次 DBS 变化关联分开解释；没有 EEG 同步证据时称为跨模态迁移实验。

遇到缺失只暂停依赖该字段的阶段，继续能完成的部分；明确给出实际完成、未完成和缺失项。不要用模拟数据的显著性冒充真实结果。
