# V9 固定模板表达与 M1 权重分解

影像、状态编号、患者配对及有效窗口沿用 V7。临床数据沿用 V8 的 33 项原始总分。报告以 25 人日期不限样本进行可比分析，双侧日期核实的 22 人作固定敏感性。

## 分解和测量

- 对每次扫描计算 M1 占用率 C、GFP² 权重 W、拟合 F 与 R=W/C。按患者计算 C 和 R 差与均值，再乘两条件的平均 F。两个分量之和复原原 W 的 Shapley 贡献，原空间拟合项沿用。缺少有效分母或拟合的配对记为不可分解。
- 用逐帧归档的原始折内编号核对状态列。将相关值裁剪到原极性不变定义的 0–1 范围，再按规定映射转为冻结编号。先复现原四态硬标签 GEV，然后只输出 M1 和 M4 的全窗连续加权平方相关。窗口中的无效帧不参与任何分母。
- 贡献份额使用同一患者重抽中的贡献均值除以原 W 贡献的均值。组级份额沿用 V7 的 0.10 个百分点及总变化区间规则。

## 四项推断

- A1、A2 分别检验占用与相对幅度的贡献。以患者级符号翻转检验双侧配对均值。FD 与 DVARS 按 V7 原调整模型重算。每种模型使用 Holm2，并将 V7 六项原始置换 P 纳入 Holm8。
- B1、B2 分别以 100×ΔE1、100×ΔE4 预测 OFF−ON 总分改善。主模型同时调整 OFF 参考分和 ΔFD。采用 V8 的患者间约简模型残差置换和双侧 HC3 统计量。保留 OFF 参考分的无头动模型、替换 ΔDVARS 和 22 人核实子集各为固定敏感性。各模型报告两项留一影响。用两项新增关联做 Holm2，并将 V8 同口径的十二项原始置换 P 纳入 Holm14。
- 每项尝试 10,000 次置换、2,000 次患者 Bootstrap，种子固定为 7261126。不可估计的 P 在校正中以 1 占位，在输出标记 NA。A 与 B 各自按登记清单完整运行。
