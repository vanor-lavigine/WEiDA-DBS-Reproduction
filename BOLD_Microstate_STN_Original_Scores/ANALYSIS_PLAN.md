# V8 原始 STN 运动评分与冻结微状态

以 V7 e53035d 为影像基线。复用 AAL78、A3、N0/G1/S1、四态、λ=0.04、TR 2.1 秒、0.01–0.08 Hz 及原五折窗口。逐人 V7 GEV、M4 Duration 与 Shapley 分量按原 V6 的患者和两次扫描键复核。

## 确定队列与计分

- 主工作簿的 33 项临床原值按预设列和语义验证后求和。强直、运动徐缓、震颤分别保留 5、11、10 项。用药与 DBS 开关分列。缺失、非整数或超出 0–4 的项保留异常依据，涉及该项的分数为空。
- 第二表以身份、评估日期、DBS 和用药条件连接。比较临床条目及派生值，保留 AT 缓存和公式、五个 AI 项及偏差。额外记录仍留作候选。
- 人口学工作簿只展开真实合并单元格。原 105 名册事先保存的字节和哈希均核对，以代码、原始研究姓名和两侧扫描键确认映射。人口学的名称异写单独登记。明确非对称靶点按备注登记。
- 访视确认要求原评分日期与已审计 DICOM 采集日期在对应 DBS 条件下吻合。两侧均核实为同日者进入已核实子集。缺独立日期证据但身份与条件一致者可进入总体探索性模型。出现日期冲突时排除整对。所有原始记录、冲突证据和扫描键均在私有审计中留存。

## 预定推断

影像差为 ON−OFF，改善量为 OFF−ON。三个总分模型分别使用 M1 GEV、M4 平均持续时间、M1 幅度权重贡献。每次拟合同时调整本域 OFF 参考分与 ΔFD。总分用 Holm3。强直、运动徐缓、震颤按相同三个预测量拟合，九项用 BH9。12 项置换 P 同时给出 Holm12。各调整模型独立校正。不可估计的项在校正时以 1 占位，展示为 NA。

先在冻结旧队列复算原四终点 Spearman 与原 FD 秩回归，再在当前可纳入人员中分别换用旧、重新计分的总分。该比较保持旧的检验定义，评估评分和纳入改变各自的影响。

新模型使用约简模型 OLS 残差的患者间 Freedman–Lane 置换，双侧 HC3 影像系数统计量。有足够组合时取 10,000 个不同的非原顺序排列，小样本时穷举。2,000 次患者整行 Bootstrap 给出系数的百分位区间。要求满秩和非零残差自由度，登记不可估计的设计和重抽。头动、同日访视子集、百分比改善及逐人留一均预先设定。百分比的分母为对应域 OFF 分，OFF=0 时记 NA。留一报告系数及变动范围，主分析保留全部合格病例。
